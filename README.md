高效、稳定、全自动化的 **Microsoft Rewards** 积分赚取与打卡系统。采用 **原生 Edge/Chrome WebDriver 驱动 + 底层反检测指纹隐匿 + 真实前台视口与物理鼠标拟真 + 全任务状态先测后跳 + Windows 计划任务后台无感静默执行**，免除每日手动繁琐操作。

---

## ✨ 核心特性

- ⚡ **全任务“先检测，已完成则跳过”**：
  - 所有任务在启动前均先核验微软官方服务器的打卡状态。
  - 若今日已经完成，直接显示状态并**瞬间跳过**，绝不盲目重复执行或无效挂机，整套检测仅需不到 40 秒！
- 🎯 **每日活动 (Daily Set) 全自动打卡**：
  - 自动识别并执行主面板 3 项每日必做任务（自动过滤兑换卡与非任务项）。
  - 智能测验 (Quiz)、投票 (Poll)、快速活动求解，官方绿色对勾（✔）精确核验。
- 📷 **必应视觉搜索连续打卡 (Visual Search Streak)**：
  - 自动定位视觉搜索卡片并检测打卡状态（`活动: 1/1`）。
  - 通过本地高质图标文件直接调用原生文件检索通道，稳定触发打卡信标，轻松保持连续连胜印章（+5 分）。
- 🌐 **Edge 浏览器 30 分钟后台静默浏览打卡**：
  - 实时读取微软后台打卡进度（如 `30/30 分钟`），已完成则直接跳过。
  - 自动激活官方打卡信标通道，在丰富百科与新闻内容池中自然翻阅与微滚动，保持视口活跃。
  - 周期性轮询微软服务器记录，达到 30/30 分钟自动优雅收尾。
- 🔍 **PC 桌面端必应搜索【倒数第二阶段 · 动态差额补齐】**：
  - **绝不盲搜**：安排在 Edge 浏览之后执行，优先打开【积分明细】抽屉读取微软官方记录（`必应搜索 当前/60`）。
  - **已满 60/60 直接跳过（0 次搜索）**；若未满分，按差额精确计算所需搜索次数并精准补齐，彻底规避风控与频控。
- 🎁 **自动领取待入账积分【最后收尾阶段 · 闭环核验】**：
  - 安排在所有任务全部完成后的最后关卡，统揽当日产生的全部积分。
  - 精准点击抽屉内部的【领取积分】按钮，一键划转入库。
  - **二次检测核验确认**：领取后重新扫描抽屉与仪表盘，确认可领取积分已归零（0），并报告最新可用总积分。
- ⏰ **Windows 计划任务全自动静默托管**：
  - **人性化时间设置**：支持自然时间输入，如输入 `8.30` 即代表 `08:30`，直接回车默认 `08:30`。
  - 无控制台黑框、无弹窗、不抢占鼠标焦点，完全后台静默执行。
  - 支持 **开机自动补跑机制**：若设定时间电脑处于关机状态，开机登录后立即自动补跑。
- 🚀 **极简跨电脑移植体验**：
  - 自动排除本机锁定的缓存与凭证文件，代码纯净打包体积小于 100 KB。
  - 复制到新电脑仅需运行一次配置向导即可永久自动运行。
- 🧹 **底层防缓存膨胀与瘦身优化**：
  - 底层限制浏览器磁盘缓存体积，杜绝自动下载臃肿组件包。
  - 配套一键瘦身脚本，在 100% 保留登录凭证的前提下深度清理临时垃圾。
- 🧩 **双模运行：附带 Manifest V3 浏览器扩展**：
  - 额外提供纯前端浏览器插件（位于 `extension/`），支持在 Edge / Chrome 开发者模式下一键载入。

## 🔄 全自动执行链路规范

为了确保积分收益最大化且绝不盲目多搜，程序将打卡全过程严格规范为以下 **6 个先后阶段**：

```text
阶段 1: 每日活动 (Daily Set 3项)        ──> 检查 3/3，已完成则跳过
阶段 2: 积分赚取 (Earn 日常与周期任务)   ──> 检查各卡片，已完成/未解锁则跳过
阶段 3: 必应视觉搜索连续打卡             ──> 检查 活动: 1/1，已完成则跳过
阶段 4: Edge 30 分钟后台静默浏览        ──> 检查 分钟: 30/30，已满额则跳过
阶段 5: 【倒数第二】PC 桌面端必应搜索    ──> 核验积分明细 60/60，已达标跳过(0搜)，未达标按缺额精准补齐
阶段 6: 【最后压轴】领取待入账奖励积分   ──> 检查可领取积分，0则跳过；>0一键领取并在领取后二次核验确认清零
阶段 7: 输出最终积分战报与连胜天数并安全释放浏览器
```

## 🚀 快速上手

### 💻 方式一：本机直接运行与使用

1. **克隆仓库**：
   ```bash
   git clone https://github.com/GZ2z2z/MicrosoftAutoRewards.git
   cd MicrosoftAutoRewards
   ```

2. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
   *注意：系统推荐安装有 Microsoft Edge 或 Google Chrome 浏览器。*

3. **初次登录微软账号**：
   - 双击 `run.bat`，输入选项 `[7]`，在弹出的浏览器窗口中登录您的微软账号。
   - 登录成功后直接关闭浏览器即可，登录状态会永久保存在本地独立目录中。

4. **开启每日全自动定时打卡**：
   - 双击运行 `安装每日定时任务.bat`。
   - 提示输入打卡时间：输入 `8.30`（代表 `08:30`）或直接按【回车键】使用默认时间 `08:30`。
   - 从此电脑每天将在后台静默自动完成全部任务，彻底无需人工干预！

---

### 📦 方式二：移植到另一台电脑（极简 3 步）

> [!TIP]
> Windows 对登录凭据使用本机专有硬件密钥加密（DPAPI），因此跨电脑迁移时仅需在新电脑登录一次即可永久有效。

1. **打包/复制代码**：
   - 在已配置电脑上双击 `打包移植压缩包.bat` 生成 `Microsoft_rewards_portable.zip`（不到 100 KB）。
   - 将压缩包复制到另一台电脑并解压到任意文件夹。
2. **运行配置向导**：
   - 双击 `一键配置新电脑(初次使用).bat`。
   - 脚本将自动检测 Python 环境、自动安装依赖、弹出窗口供登录一次微软账号，并自动配置每日定时任务。
3. **享受全自动化**：
   - 配置完成，后续无需打开任何窗口。

## ⚙️ 命令行参数

主程序 `rewards_runner.py` 支持丰富的命令行参数：

| 参数 | 描述 |
| :--- | :--- |
| `--headless` | 开启无头静默模式（后台静默执行，写入日志） |
| `--visual` | 仅执行必应视觉搜索连续打卡 |
| `--claim` | 仅检查并自动领取待入账积分（附带二次核验） |
| `--browse30` | 独立执行 Edge 30 分钟后台静默浏览打卡 |
| `--no-browse30` | 在全自动模式中跳过 30 分钟浏览打卡 |
| `--daily` | 仅执行每日活动卡片（Daily Set + Earn 任务） |
| `--search` | 仅执行 PC 桌面端必应搜索（优先读取积分明细差额） |
| `--count N` | 指定单次必应搜索最大上限（默认 22 次，自动核验补足至 60/60 满分） |
| `--time TIME` | 指定每日定时任务执行时间（例如 `8.30` 或 `08:30`，默认 `08:30`） |
| `--browser` | 选择浏览器引擎（auto/chrome/edge，默认为 auto） |
| `--login` | 打开前台浏览器窗口供首次登录账号 |
| `--clean` | 深度清理运行时产生的缓存垃圾 |
| `--install-task` | 注册/更新 Windows 每日定时打卡任务 |
| `--uninstall-task`| 从系统计划任务中卸载自动任务 |
| `--view-log` | 使用记事本查看运行日志 |
| `--setup` | 启动新电脑初始化配置向导 |
| `--pack` | 生成用于跨电脑移植的纯净压缩包 |

## 🧩 浏览器插件模式使用说明

如果您希望直接在现有的浏览器内进行轻量级前端打卡：
1. 打开浏览器扩展管理页面：
   - Edge: `edge://extensions/`
   - Chrome: `chrome://extensions/`
2. 打开右上角 **“开发者模式”** 开关。
3. 点击 **“加载已解压的扩展程序”**，选择项目根目录下的 **`extension`** 文件夹。
4. 点击右上角扩展栏图标，点击【⚡ 一键开始全部任务】即可。

## ❓ 常见问题排查 (FAQ)

<details>
<summary><b>Q1: 为什么我的定时任务没有在指定时间跳出黑框？</b></summary>
这是专为免打扰设计的特性！程序通过 <code>silent_run.vbs</code> 实现了完全后台无弹窗静默运行。您可以双击 <code>查看运行日志.bat</code> 或查看 <code>logs/rewards.log</code> 确认任务执行进度与积分结算情况。
</details>

<details>
<summary><b>Q2: 电脑在设定的打卡时间处于关机状态怎么办？</b></summary>
无需担心！在注册 Windows 计划任务时已启用 <code>StartWhenAvailable</code>（开机立即补跑）参数。只要电脑开机进入桌面，系统会在几分钟内自动启动后台打卡补跑。
</details>

<details>
<summary><b>Q3: 设置定时任务时输入时间的格式有什么要求？</b></summary>
程序已内置智能时间解析器：输入 <code>8.30</code> 会自动识别为 <code>08:30</code>，同时也支持 <code>8:30</code>、<code>08:30</code>、<code>9.00</code>、<code>12.30</code> 等常见格式；直接回车默认按 <code>08:30</code> 设定。
</details>

<details>
<summary><b>Q4: 为什么今天只用了几十秒就结束了？</b></summary>
程序具备全面的<b>“先检测，已完成则跳过”</b>特性。如果当天的每日任务、视觉搜索、Edge 30分钟或 60 分搜索已经满额达成，程序会直接跳过对应环节，绝不做无效重复操作。
</details>

<details>
<summary><b>Q5: 项目运行一段时间后体积会变大吗？</b></summary>
不会。底层驱动已严格限制磁盘缓存大小为 10MB 并禁用了组件自动更新。您也可以随时双击 <code>清理缓存垃圾.bat</code> 进行彻底瘦身。
</details>
